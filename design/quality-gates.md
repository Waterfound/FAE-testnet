# FAE Visual Quality Gates — Mining Authored Reference

## Authoritative identity (PR #268)
- Does the surface clearly derive from the frozen FAE Mining Authored Reference identity, rather than from historical D/D+/VL-08 prototypes?
- Does it preserve intentional authored composition, product-first task clarity and quiet/active contrast without mechanically cloning Mining layout?
- Does it remain recognizably FAE without the logo?
- Are orange/white/blue/green applied to their proper semantic roles?
- Does it avoid generic SaaS, exchange, Web3 and financial-terminal language?
- Is the authoritative binding present and correct in `docs/FAE_VISUAL_IDENTITY_AUTHORITY_20261007.json`?

## Topper / network ticker
- Are core network facts compact rather than large fixed balloons?
- Is horizontal motion readable rather than frantic?
- Does reduced motion preserve the information?
- Can status be understood without color?

## White field
- Is the working surface predominantly light, readable and calm?
- Are cards used only for meaningful containment?
- Does spacing create hierarchy without wasting operational space?

## Blue circulation
- Is blue consistently reserved for live/active/focus/processing states?
- In Mining, is the activity rail explicitly non-deterministic?
- Is there no language implying percentage-to-reward, ETA-to-block or “almost won”?

## Wallet
- Is Wallet creation strictly explicit, with no implicit wallet generation on visit, mode change or reload?
- Does the Wallet feel calm and restful relative to Mining's activity?
- Are ownership, signing locality, recovery and transaction traceability clearer than branding?
- Are seed/recovery surfaces sober and high-contrast?
- Are send/receive/history actions immediately discoverable?

## Mining
- Is the PR #268 authored reference frozen, with no redesign or functional miner change admitted through visual propagation?
- Does the interface feel alive without feeling like gambling?
- Is device contribution visible?
- Does the activity visualization stop/settle correctly when work stops?

## Accessibility
- Relevant contrast measured before integration.
- Visible keyboard focus.
- State not color-only.
- Reduced motion supported.
- Mobile security copy remains readable.

## Gate
A surface passes only when **authored identity + functional invariants + semantic honesty + task clarity + accessibility** survive together. Historical visual studies are provenance, not competing authority. A missing or inconsistent authoritative identity binding fails closed.
