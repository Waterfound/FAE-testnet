# FAE Mining Manifesto Notes

Status: documentation / manifesto note  
Date: 2026-10-03  
Authority: conceptual design note only; this document does not create consensus, economic, release, or mainnet authority.

## General-purpose capacity over dedicated mining infrastructure

FAE should prefer a mining economy in which useful general-purpose hardware remains economically relevant instead of forcing participants toward equipment whose primary reason to exist is mining.

A simple analogy:

> **Bitcoin is like paying $100 per month for access to specialized equipment and doing 15 minutes of very intense exercise each day. FAE aims to be more like using the park and the body you already have for a 90-minute walk: the individual activity may be longer and heavier, but it relies more on general-purpose capacity that already has value outside the activity.**

The analogy is intentionally economic rather than literal. FAE mining is not free, and a longer/heavier work unit does not automatically mean lower energy consumption. The desired distinction is that a participant should not need to buy highly specialized hardware that has little value outside mining.

Compact principle:

> **Bitcoin buys dedicated efficiency. FAE tries to reuse general-purpose capacity.**

This complements the mining-design principle:

> **FAE tenta transformar mineração de uma corrida por compute density em uma corrida por memory economics.**

The intended long-term outcome is that computers people already own for work, creation, gaming, development, local AI, or other general-purpose use can remain meaningful participants in FAE mining, while specialist hardware must continue paying substantial memory-system, bandwidth, controller, packaging, and data-movement costs.

This is an architectural and economic design intent, not proof that DP6 has already achieved the desired specialist bound.
